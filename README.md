# 1502 Golf for Windows

Official Windows installer downloads for [1502 Golf](https://golf.1502apps.com).

## Download

[Download 1502 Golf 0.13.1 for Windows](https://github.com/cswan1502/1502-golf-downloads/releases/download/v0.13.1/1502Golf-Setup-0.13.1.exe)

Install the Windows game on your PC, then use your phone to join and control play. Visit [golf.1502apps.com](https://golf.1502apps.com) for the phone app and setup.

The installer is not digitally signed. Windows may show an unknown-publisher or Microsoft Defender SmartScreen warning.

The SHA-256 checksum is provided in [SHA256SUMS.txt](SHA256SUMS.txt) and the release notes.
